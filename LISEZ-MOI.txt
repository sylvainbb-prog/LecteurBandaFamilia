LA BANDA FAMILIA – APPLICATION DE RÉPÉTITION
=============================================

Contenu du dossier
  index.html            l'application
  sw.js, manifest...    ce qui la rend installable et utilisable hors connexion
  icons/                icônes de l'application
  morceaux/             les partitions (.mxl), leur liste (songs.json) et calibrage.json
                        (mise en page pré-calculée : ouverture des morceaux plus rapide)
  sons/                 (à créer une fois, voir plus bas) les sons d'instruments

METTRE EN LIGNE (gratuit, une seule fois, ~10 minutes) – GitHub Pages
  1. Créer un compte sur https://github.com (gratuit).
  2. Bouton « + » en haut à droite → « New repository ».
     Nom : banda   ·   Public   ·   « Create repository ».
  3. Sur la page du dépôt : « uploading an existing file ».
     Glisser TOUT le contenu de ce dossier (index.html, sw.js, manifest.webmanifest,
     LISEZ-MOI.txt, et les dossiers icons et morceaux) → « Commit changes ».
  4. « Settings » → « Pages » → Source : « Deploy from a branch »,
     Branch : « main » et « / (root) » → « Save ».
  5. Une minute plus tard, l'application est en ligne à l'adresse :
        https://VOTRE-COMPTE.github.io/banda/
     C'est ce lien (ou le QR code de la séance) que vous donnez aux musiciens.

INSTALLER SUR UN TÉLÉPHONE
  iPhone / iPad : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».
  Android      : ouvrir le lien dans Chrome → bouton « Installer l'application »
                 (ou menu ⋮ → « Installer l'application »).
  Ordinateur   : Chrome / Edge → icône d'installation dans la barre d'adresse.

HORS CONNEXION (concert)
  Avec une connexion, ouvrir l'application et toucher « Hors connexion » :
  tous les morceaux et les sons sont téléchargés. Ensuite tout fonctionne sans réseau
  (sauf la séance synchronisée, qui a besoin d'internet pour relier les téléphones).

AJOUTER OU MODIFIER UN MORCEAU
  Dans MuseScore : Fichier → Propriétés du projet → renseigner le Titre,
  désactiver « Son réel », puis Fichier → Exporter → MusicXML compressé (.mxl).
  Sur GitHub : ouvrir le dossier « morceaux » → « Add file » → « Upload files ».
  Nommer le fichier avec son numéro, par exemple « 12 - Nouveau morceau.mxl » :
  il apparaît automatiquement dans la liste (trié par numéro).
  Pour remplacer un morceau, déposer un fichier portant exactement le même nom.

HÉBERGER LES SONS AVEC L'APPLICATION (une fois, recommandé)
  Sans ce dossier, les sons viennent d'un site gratuit externe ; avec, l'application est autonome.
  1. Ouvrir l'application (en ligne), Paramètres → « Créer le pack de sons (sons.zip) ».
     Patienter quelques minutes : le fichier sons.zip (60 à 90 Mo) est téléchargé.
  2. Décompresser sons.zip : on obtient un dossier « sons ».
  3. Sur GitHub, page du dépôt → « Add file » → « Upload files » → glisser le dossier « sons »
     → « Commit changes ». (Chaque fichier fait moins de 25 Mo : l'envoi par le site marche.)
  4. Paramètres de l'application : la ligne « Sons hébergés avec l'application : N banques ✓ » le confirme.
  Quotas GitHub (gratuit) : dépôt et site jusqu'à 1 Go, fichiers jusqu'à 100 Mo, trafic ~100 Go/mois.
  Le pack de sons fait moins de 10 % du quota ; les téléphones ne le téléchargent qu'une fois
  (ensuite il est gardé dans l'appareil), donc le trafic reste très faible.

METTRE À JOUR L'APPLICATION
  Déposer la nouvelle version de index.html (et sw.js) au même endroit sur GitHub.
  Les téléphones la récupèrent automatiquement à l'ouverture suivante.

NOTE
  Les fichiers .mxl préparés par Claude contiennent en plus la mise en page de chaque
  partie séparée (mode « Comme imprimé »). Un export fait directement depuis MuseScore
  fonctionne aussi : ce mode utilise alors les lignes du conducteur.
